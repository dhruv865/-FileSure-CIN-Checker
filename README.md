
# FileSure – CIN & LLPIN Checker

FileSure is a simple web-based tool that checks the format of Indian Company Identification Numbers (CIN) and Limited Liability Partnership Identification Numbers (LLPIN).

## Features

- Validate CIN and LLPIN formats.
- Process multiple entries at once.
- Display valid and invalid results.
- Identify duplicate entries.
- Decode available CIN information such as state, year and company type.
- Display validation errors.
- Export results to CSV.
- Load sample data for testing.
- Responsive user interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter CIN or LLPIN values.
5. Click Validate to see the results.

## Important Note

FileSure performs format-based validation only. It does not verify company or LLP registration details against live MCA records.

## Project Purpose

Developed as a practical web development project to demonstrate frontend development, input validation, data processing and CSV export functionality.
